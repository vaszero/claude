# 병원 CS 플레이

병원 CS 강의용 **QR 참여형 실시간 교육 게임**입니다.
큰 화면(프로젝터)에 QR을 띄우면 직원들이 앱 설치 없이 휴대폰으로 입장하고, 휴대폰이 컨트롤러가 됩니다.

| 순서 | 프로그램 | 강의에서의 역할 |
|---|---|---|
| 1 | **입장** | QR 입장, 닉네임 + 부서 선택 |
| 2 | **사전·사후 진단 퀴즈** | 같은 7문제를 강의 전·후에 풀어 정답률 변화를 숫자로 보여 줌 |
| 3 | **응대 멘트 투표** | 실제 병원 상황 7개에서 가장 좋은 응대를 고르고, 결과 분포를 보며 토론 → 강사 포인트 |
| 4 | **금지 멘트 잡기** | 60초 두더지잡기. 금지 멘트만 터치, 좋은 멘트를 누르면 -50점 → 끝나고 "바꿔 말하기" 정리 |
| 5 | **부서 대항 OX** | 10문제. 부서별 **정답률**로 점수를 매겨 인원이 적은 부서도 공평하게 겨룸 |
| 6 | **익명 워드클라우드** | "가장 힘든 순간은?" 같은 질문에 익명으로 답하면 단어 구름으로 표시 |
| 7 | **결과 리포트** | 참여 인원, 사전→사후 향상률, 투표·OX·게임 결과 → CSV(엑셀)·PDF 저장 |

---

## 1. 내 노트북에서 바로 쓰기 (가장 간단)

준비물: [Node.js](https://nodejs.org) (LTS 버전) 설치

```bash
npm install
```

```bash
HOST_KEY=원하는비밀번호 npm start
```

> Windows PowerShell에서는 `$env:HOST_KEY="원하는비밀번호"; npm start`

실행하면 화면에 이렇게 나옵니다.

```
 강사 화면 : http://localhost:3000/host?key=원하는비밀번호
 같은 와이파이 참가자 : http://192.168.0.12:3000
```

- 노트북 브라우저에서 **강사 화면** 주소를 열고 프로젝터에 띄웁니다.
- 화면의 QR에는 노트북의 와이파이 주소가 자동으로 들어갑니다.
- ⚠️ 이 방식은 **참가자 휴대폰이 노트북과 같은 와이파이에 연결돼 있어야** 합니다. 병원 와이파이가 손님용/직원용으로 분리돼 있으면 안 될 수 있어요. 그럴 때는 아래 2번(인터넷 배포)을 쓰세요.

## 2. 인터넷에 올려서 쓰기 (추천: 어느 병원이든 데이터로 접속 가능)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/vaszero/claude)

위 버튼을 누르면 아래 1~2번이 한 번에 진행됩니다. (기본 콘텐츠는 연세일등정형외과 세트이며, Render 환경변수 `CONTENT_FILE`에서 바꿀 수 있습니다.)

[Render](https://render.com) 무료 플랜 기준입니다.

1. Render 가입 → **New → Blueprint** → 이 GitHub 저장소 선택
2. `HOST_KEY` 값을 물어보면 진행자 비밀번호를 입력
3. 배포가 끝나면 `https://cs-play-xxxx.onrender.com/host` 로 접속 → 비밀번호 입력

⚠️ **무료 플랜은 15분 동안 안 쓰면 잠듭니다.** 강의 시작 **10분 전에 강사 화면을 미리 열어** 깨워 두세요(처음 깨어날 때 1분 정도 걸립니다).
⚠️ 무료 플랜은 서버가 재시작되면 저장 파일이 사라집니다. **강의가 끝나면 반드시 [결과 리포트 → CSV 다운로드]** 를 눌러 보관하세요.

## 3. 강의 진행 방법

강사 화면 아래쪽 진행 도구로 조작합니다. 키보드와 **프레젠테이션 리모컨(포인터)** 도 됩니다.

| 키 | 동작 |
|---|---|
| `1` ~ `7` | 프로그램 이동 |
| `→`, `스페이스`, 리모컨 다음 버튼 | 다음 단계 (결과 공개 → 강사 포인트 → 다음 상황 등) |
| `←`, 리모컨 이전 버튼 | 이전 상황 / 이전 질문 |
| `H` | 진행 도구 숨기기·보이기 |
| `F` | 전체 화면 |

**추천 2시간 배치**

| 시점 | 프로그램 |
|---|---|
| 시작 | 1 입장 → 2 사전 퀴즈 → 6 워드클라우드 질문 1 (가장 힘든 순간) |
| 30분 뒤 | 4 금지 멘트 잡기 (분위기 전환) → 바꿔 말하기 정리 |
| 본 강의 중 | 3 응대 멘트 투표 (사례 강의 사이사이에 하나씩) |
| 후반 | 5 부서 대항 OX |
| 마무리 | 6 워드클라우드 질문 4 (실천할 한 가지) → 2 사후 퀴즈 → 7 결과 리포트 |

**진행 팁**
- 사전 퀴즈 결과 화면은 정답을 공개하지 않고 "가장 많이 틀린 문항"만 보여 줍니다. 강의 도입부 훅으로 쓰세요.
- 워드클라우드에 부적절한 단어가 나오면 **그 단어를 클릭**하면 화면에서 바로 숨겨집니다.
- 강의 중간에 늦게 온 직원은 화면 오른쪽 위 작은 QR로 언제든 입장할 수 있습니다.
- 한 강의가 끝나고 다음 강의를 하기 전에는 **세션 초기화**를 누르세요. (초기화 전 결과는 서버 `data/` 폴더에도 자동 저장됩니다.)

## 4. 문제·사례 바꾸기

모든 내용은 `content/hospital-cs.json` 한 파일에 있습니다. 메모장으로 열어서 고치면 됩니다.

- `departments` : 부서 목록 (병원에 맞게 예: "원무·접수", "간호", "물리치료" …)
- `quiz` : 사전·사후 퀴즈. `answer`는 **1부터 세는** 정답 번호
- `scenarios` : 응대 멘트 투표. `best`는 1부터 세는 추천 번호, `point`는 강사 포인트
- `whack.bad` : 금지 멘트(`text`)와 바꿔 말하기(`alt`) / `whack.good` : 함정용 좋은 멘트
- `ox` : OX 문제. `answer`는 `"O"` 또는 `"X"`
- `cloudPrompts` : 워드클라우드 질문
- `settings` : 금지 멘트 게임 시간(초), OX 제한 시간(초), 워드클라우드 1인당 응답 수

### 병원별 콘텐츠

| 파일 | 대상 |
|---|---|
| `content/hospital-cs.json` | 병·의원 공통 기본 세트 |
| `content/yonsei-ildeung-siheung.json` | 연세일등정형외과의원(시흥) — 물리치료실 대기, 실손보험 문의, 주사 후 전화, X-ray 재촬영 사례 포함 |

병원별로 파일을 따로 만들어 두고 `CONTENT_FILE=content/○○병원.json npm start` 처럼 골라서 쓸 수도 있습니다.
Render에서는 환경변수 `CONTENT_FILE`에 `content/yonsei-ildeung-siheung.json`을 넣으면 됩니다.
파일 형식이 틀리면 서버가 켜질 때 어느 문항이 잘못됐는지 알려 줍니다.

### 병원 로고 넣기

1. 로고 이미지(PNG, 배경 투명 권장)를 `public/logos/` 폴더에 넣습니다. 예: `public/logos/yonsei-ildeung.png`
2. 콘텐츠 파일의 `"logo"` 값을 `"/logos/파일이름.png"` 로 맞춥니다.

로고는 강사 화면 상단, 입장 화면, 결과 리포트, 참가자 휴대폰 상단에 표시됩니다. 파일이 없으면 로고 자리만 비고 나머지는 그대로 동작합니다.
병원 로고는 해당 병원의 동의를 받은 강의에서만 사용하세요.

## 5. 강의 전 리허설

가상 참가자를 띄워서 혼자서도 전체 흐름을 미리 돌려 볼 수 있습니다.

```bash
npm install
```

```bash
node scripts/simulate.js 25 http://localhost:3000
```

강사 화면을 넘기면 가상 참가자 25명이 퀴즈·투표·게임·OX·워드클라우드에 자동으로 응답합니다.

## 개인정보 관련

- 참가자는 **닉네임**과 **부서**만 입력합니다. 실명이나 연락처는 받지 않습니다.
- 퀴즈 점수·투표·워드클라우드는 이름 없이 집계됩니다. 게임 순위에만 닉네임이 표시됩니다.
- 실제 환자 사례를 문제로 쓸 때는 특정 환자를 알아볼 수 있는 정보를 빼고 각색하세요.
